Expojet generates an Expo SDK 57 app from the options you choose. Start with the interactive command, or use flags to repeat a configuration.

```bash
npx create-expojet@latest my-app
```

## Start a project

- [Installation](/docs/installation) covers the requirements and the first command.
- [Quick start](/docs/quick-start) walks through a standalone app.
- [Project structure](/docs/folder-structure) shows where generated files live.
- [Stack Builder](/builder) gives you a CLI command for the options you select.

## Choose your stack

Expojet can generate a standalone mobile app or a monorepo with an API. The guides explain each choice and its setup:

- [Navigation](/docs/guides/navigation/expo-router)
- [Styling](/docs/guides/styling/options)
- [Authentication](/docs/guides/authentication/providers)
- [Backend](/docs/guides/backend/frameworks)
- [Database](/docs/guides/database/providers)

## CLI reference

Use [create](/docs/cli/create) for flags and non-interactive runs. If a generated project needs a check, run [`expojet doctor`](/docs/cli/doctor).
