---
title: NativeWind
description: Tailwind-compatible styling for Expo and React Native.
---

NativeWind is available through the `--style nativewind` adapter.

```bash
npx create-expojet@latest my-app --style nativewind
```

Expojet wires the Metro configuration, CSS entrypoint, and type declarations for the generated app. It works in standalone apps and monorepos.
