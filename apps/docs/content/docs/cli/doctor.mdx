title: expojet doctor
description: Read-only compatibility, workspace, lockfile, and secret-boundary checks.
---

```bash
npx expojet doctor
```

Doctor checks Node.js, the Expojet manifest, SDK compatibility, lockfiles, workspaces, and server-secret leakage into mobile files. Better Auth receives an experimental warning until its physical-device gate passes.

Use `npx expojet info` for a copyable, secret-free support report. Doctor never edits files.
