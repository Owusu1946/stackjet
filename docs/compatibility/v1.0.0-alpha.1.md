## 3. Secret Isolation Certification

Every generated application has been scanned against the following invariants:
- **Zero Server Secrets in Mobile Bundle**: Verified via `Mobile secret boundary` doctor check. Neither `CLERK_SECRET_KEY`, `DATABASE_URL`, nor `DIRECT_DATABASE_URL` exist in mobile workspace files or bundled outputs.
- **Explicit Public Classification**: All client-accessible environment values must bear the `EXPO_PUBLIC_` prefix and be defined in `@t3-oss/env-core` client schemas.

---

## 4. Known Limitations & Non-Goals

1. **Expo Go OAuth Limitation**: Custom OAuth schemes requiring deep links require a development build (`npx expo run:android` or `npx expo run:ios`) or EAS Build.
2. **Older SDK Support**: SDK 54, 55, and 56 are not supported in v1 to ensure store policy compliance and minimize maintenance overhead.
3. **Database Client Direct Imports**: Mobile clients must query through the Hono API server using Hono RPC. Direct database queries from mobile are intentionally prevented.
